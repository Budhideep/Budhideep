# Day 1 Lab

## Pro Git – Git Learning Material

This folder contains the **Pro Git – Second Edition** PDF by Scott Chacon and Ben Straub. The PDF provides a comprehensive introduction to Git, its commands, concepts, and workflows.

### Topics Covered

* Version Control Systems
* Git Basics
* Git Installation and Configuration
* Git Commands
* Recording and Managing Changes
* Commit History
* Branching and Merging
* Remote Repositories
* GitHub
* Advanced Git Commands
* Git Configuration
* Git Internals
* Git Command Reference

The book also contains a dedicated **GitHub** chapter covering account setup, repositories, workflows, and GitHub-related tools.

### File

* `ProGit.pdf` – Git learning material

### Purpose

This repository is created to store and organize the learning material and practical work related to Git and GitHub.
